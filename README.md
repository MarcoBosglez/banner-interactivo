# Custom Interactive Web Banner for ONErpm [https://marcobosglez.github.io/banner-interactivo/]

A custom frontend web development and digital design project created for a commercial music distribution campaign (ONErpm / Spotify playlist release). 

This project showcases the integration of tailored visual artwork with lightweight frontend scripting to create an interactive web banner for digital promotions.

---

## 📋 Case Study Overview

- **Client Context:** Digital music distribution & promotional release (ONErpm)
- **Primary Goal:** Combine high-impact visual artwork with dynamic web elements to promote a music release across web channels and streaming platforms (Spotify).
- **Role:** Software Developer & Digital Artist (End-to-End Design & Development)

---

## 🛠️ What I Built

- **Custom Digital Artwork:** Designed promotional banner graphics formatted to meet strict platform guidelines (Spotify header specs and safe zones).
- **Interactive Scripting:** Programmed custom JavaScript logic to add dynamic UI interactions, animations, and interactive elements to the banner layout.
- **Responsive Web Layout:** Developed custom HTML5 and CSS3 styling to ensure the banner renders sharply and responsively across desktop and mobile browsers.

---

## 🧰 Tech & Tools Used

### **Development**
- **JavaScript (Vanilla JS):** Custom DOM manipulation and interactive logic
- **HTML5:** Semantic markup and layout structure
- **CSS3:** Custom styling, layout responsiveness, and visual effects

### **Design & Art**
- **Digital Illustration / Graphic Design:** Custom banner art and promotional assets
- **Asset Optimization:** Compression and sizing for fast web loading without quality loss
